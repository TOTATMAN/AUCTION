# 東亞拍賣有限公司 — AI文物鑑定系統

East Asia Auction Co., Ltd. — AI Antique Appraisal System

## Features
- 📸 Take photos of Chinese antiques (up to 3 angles)
- 🤖 AI-powered analysis using DeepSeek Vision
- 📋 Professional appraisal reports
- 📱 Mobile-friendly PWA

## Setup
1. Deploy to Vercel
2. Set environment variables:
   - `DATABASE_URL` - PostgreSQL connection string
   - `DEEPSEEK_API_KEY` - DeepSeek API key
